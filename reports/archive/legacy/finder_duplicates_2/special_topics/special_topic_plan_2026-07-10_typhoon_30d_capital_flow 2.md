## 一句總預測（Thesis）

> 下個月台股主線不是「再全面追高熱 AI 權值」，而是：  
> **錢離開擁擠的方向燈之後，先停在可驗證的承接／停泊／材料兌現段。**

觀眾聽完要記住三件事：往哪流、誰先動、什麼叫看錯。

---

## 為什麼今天做（休市正當性）

1. 台股未開盤 → 不硬做假盤後、不消耗未齊資料的 `/1`。
2. 近月（約 6 月底～7/8）已有清楚「資金搬家」軌跡，適合拉成 30 日地圖。
3. 標題自帶「對答案契約」，一個月後可複利成驗收短影／日報加碼。

## 三個預測（定稿可改）

### 預測 ①｜彈性：影子買超要補量，才算真方向

| 欄位 | 內容 |
|------|------|
| 預測句 | 下個月會反覆交易「榜外／縮量買超」能否補量站穩；**先動的是成熟製程與低位階承接段，不是再追已被當提款機的高位權值敘事。** |
| 角色 | 彈性／確認候選 |
| 代表 | **2303 聯電**（主）；**2344 華邦電**（對照：買超與股價矛盾） |
| 證據窗 | 近月多次外資大買 + 量未爆／榜外（見 7/3、7/8 等本地記憶） |
| 下個月看 | 外資是否延續；量能否跟上；關鍵均線／缺口是否守住 |
| **失效線** | 外資轉賣且放量破位；或持續大買但股價連弱 → 降級為「一日沖洗」 |
| 包裝 | 「錢先進場的地方，下個月要比的是：會不會補量。」 |

### 預測 ②｜停泊：防禦／高息是溫度計，不是主升浪

| 欄位 | 內容 |
|------|------|
| 預測句 | 若波動仍大，**一部分資金會續停在金融防禦／高息工具**；這是風險偏好溫度計，不是新主升段引擎。 |
| 角色 | 停泊／溫度計 |
| 代表 | **2883 凱基金**（近有命中脈絡）、**00919**；對照 **0050**（權值提款出口） |
| 證據窗 | 7/7 崩跌後金融避風；7/8 高息仍在買超前段 |
| 下個月看 | 急殺時是否相對抗跌；防禦與大盤相關性 |
| **失效線** | 防禦與高息與大盤同步崩、無量殺 → 系統性砍倉，不是輪動 |
| 包裝 | 「躲雨的地方要認得出來，但別把雨傘當飛機。」 |

### 預測 ③｜確認：材料／漲價鏈（含矽晶圓）要從題材變數字

| 欄位 | 內容 |
|------|------|
| 預測句 | 若半導體主線要上修，**確認段會出現在「滿載＋漲價能否落地」的材料鏈**（矽晶圓為可觀察支線），而不是再講 AI 口號。 |
| 角色 | 題材確認／產業循環 |
| 代表 | **6488 環球晶**（龍頭確認思路）；可選 **6182 合晶** 當較高彈性——**可改可不放第二檔** |
| 證據窗 | 2026 中市場對矽晶圓滿載／漲價敘事升溫；日報主線較少押此鏈 → 本集用 30 日驗證補位 |
| 下個月看 | 漲價協商是否有進展；營收／稼動率是否跟上股價 |
| **失效線** | 漲價跳票、稼動率下滑、價漲量空 → 「預期先行」降級追價 |
| 包裝 | 「不是否認矽晶圓，是給它一個月驗收單。」 |

**不寫死：** ③ 可整條換成「先進封裝利多出盡是否告一段落」（欣興類當反面教材），格式不變。

## 穩健／積極（口播一句）

- **穩健**：先認清錢從哪流出；防禦是停泊不是績效保證；失效線沒觸發再提高觀察權重。  
- **積極**：預測①出現「補量確認」後再提高彈性部位權重；③只當驗證題，不在敘事最高點無腦追。  

**不構成投資建議。**
