# Reports Archive 說明

Archive 用來保存舊資料，不是垃圾桶。所有歷史報告、prompt、YouTube 素材都應保留，方便回測與複利。

## 分類

- `01_Daily_Reports/`: 舊每日報告與 structured data。
- `02_US_Reports/`: 舊美股或週末特別報告。
- `03_NotebookLM_Prompts/`: 舊 NotebookLM prompt。
- `04_Deep_Research/`: 深度研究報告。
- `05_Portfolio_Analysis/`: 持股與投組分析。
- `06_YouTube_Assets/`: 舊 YouTube package、metadata、字幕、縮圖與素材。

## 使用規則

- Active 區只放近期仍要操作的檔案。
- Archive 裡的檔案不要隨意刪除。
- 需要分析歷史表現時，先查 `analytics_summary.md`、`06_YouTube_Assets/channel_story_log.md`，再回 archive 找當天 package。
