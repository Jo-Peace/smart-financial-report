# YouTube 包裝複利規則

這份檔案用來保存標題、縮圖與封面 prompt 的累積規則。每次測試後更新，不要只做一次性的 daily package。

## 目前有效方向

- 數據反差：盤面表象與資金數據相反。
- 具體數字：金額、檔數、點位、百分比，但只能用已驗證資料。
- 資金流向：觀眾想知道外資、主力、投信的錢去哪裡。
- AI 角色：標題要讓 AI 有「拆解、追出、找出」的功能，不只是掛名。
- 首頁瀏覽優先：若主要流量來源是「瀏覽功能」，標題與縮圖優先讓觀眾在首頁停下來，不優先寫成完整市場摘要。
- **站外導流（獨立變數，2026-07-31 確認）**：臉書發文＋在**很多相關留言下掛連結**有效抬流量。7/27 案例：分享到 FB 並 comment seeding → 公開約 423 views；Studio「直接或不明 22.9%」偏高。復盤必記 `站外=`，不能把人肉分發算成標題/視覺勝利。

## 首頁瀏覽功能優先規則

來源：YouTube / Gemini 頻道分析建議，2026-05-25 納入流程。

當影片主要由「瀏覽功能」發現時，包裝目標是提高首頁停留與點擊：

- 標題 A 優先使用「今日最大矛盾大數字 + 核心股名 + 觀眾想知道的答案」；驗收可放中後段，不可當開場字。
- 縮圖固定保留頻道辨識：左上日期、兩行大字、單一核心股名、大數字或強反差、博士 + 韭菜。
- 視覺主題可以每天換，但資訊版型不要每天推倒重來。
- 2026-09-03 A/B：A 維持完整句「外資○○億狂砍／狂掃」；B 同一檔同一數字但殘句／問句。封面 A 兩行股名+金額，B 更碎。禁止 B 用驗收章。先上 A。
- 縮圖第一眼要看得懂「哪一檔 + 發生什麼反直覺事件」。
- CTR 高但前 30 秒留存低：代表包裝有吸引力，但開場承接不足，下次要更快回答標題承諾。
- CTR 低但留存高：代表內容可用，應優先重做標題/縮圖，不急著否定選題。
- 不以單支低觀看數影片否定版型；低於 900 views 只作觀察。

## 前 30 秒開場鉤子（2026-07-22 納入）

來源：點閱樣本顯示「驗收開場」偏弱；標題承諾與開場脫節時，CTR 即使可看，前 30 秒留存仍容易掉。

- `validation_placement=brief/omit`：描述章節 **00:00 禁止**「昨日預測驗收」；必須先丟今日最大矛盾（股名 + 金額/漲跌 + 反差）。
- `validation_placement=lead`：才可用驗收當開場，但仍要先有可驗證數字。
- 開場節奏建議：0–8 秒矛盾 → 8–20 秒散戶問句 → 20–40 秒定調主線；驗收 brief 時中段一句即可。
- 聳動必須綁資料源數字；禁止沒有金額/漲跌的空泛「崩盤／逃命／毀屍」。
- NotebookLM 導演卡與 `/2` 描述章節共用同一套 placement 規則，避免標題很衝、口播卻先做驗收儀式。

## `/2` 前置：點閱回顧（2026-07-27 納入）

來源：人工要求固定紀律——不可只靠 `/1` 自動更新或對話記憶就定視覺。

**每次跑 `/2` 之前必須先做：**

```bash
python3 cli.py youtube preflight-views --refresh --recent 15
```

輸出要用來決定：

1. **標題主鉤**：優先模仿近窗「高樣本」的問法（金額＋矛盾＋可回答問題），避開低樣本公式（例如連打驗收開場、連續 AMD 開場疲乏時）。
2. **視覺主題**：與近 3 支影片構圖有差異；可延續「金融感」，但不要連三日同一家族（例如連續亮色週刊頭版）。
3. **樣本門檻**：views 低於 900 只作觀察；達 900 以上才較能當強化／淘汰依據。
4. **開場 token 疲勞（2026-08-10）**：`preflight-views` 會印 trailing 開場（AMD／驗收）。連續 2 支 WARN、≥3 支 BLOCK——BLOCK 日禁止同一 token 開場；事件名可放描述中後段。

決策回覆最少要寫四行：

```text
近窗中位/平均：...
高樣本可複製：日期 / views / 標題感或視覺
低樣本避雷：日期 / views / 避免什麼
今日視覺與主鉤：...（說明為何與近 3 日不同）
開場疲勞：WARN|BLOCK|ok + token
```

完成以上才呼叫 `regen-assets`。

## 每日主軸選擇規則

來源：人工校正，2026-05-26 納入流程。

不要每天都把影片包成「資金流、背離、警報、退潮」。這些詞如果天天用，會變成另一種空泛公式。

每次 `/2` 先判斷今日最適合哪一種主軸，只選一種：

- 驗收日：昨天或上集點名標的有明確命中/失準，且數字足夠形成連續追蹤。
- 重大事件日：美股、ADR、Fed、匯率、關稅、地緣政治、長假、財報等才是最大鉤子。
- 異常日：法人買賣、成交量、股價之間有明確反直覺數字。
- 續航日：同一標的或族群至少 2-3 天有法人、量能、價格結構支持。
- 主題日：同產業至少 3 檔同向，且不是只靠單一個股硬代表族群。
- 整理日：沒有強訊號時，主軸放在「等待確認、觀察條件、不要追強」。

使用限制：

- 「資金輪動」不是主軸，因為它是市場常態。
- 「背離 / 警訊 / 退潮」只能在數據支持時使用。
- 「續航 / 接棒 / 主力還在」必須有多日延續證據。
- 整理日不硬做危機感；可信度比聳動更重要。
- 連續兩集避免使用同一種情緒公式，除非數據真的延續。

建議標題 A：

```text
外資狂砸60.2億買聯電，成交量卻沒進榜？｜AI帶你看股市
```

（驗收若要寫，放中後段，例如：「…沒進榜？昨天點名華邦電也驗收了｜AI帶你看股市」）

建議縮圖文字：

```text
核心股名
外資買XX億
```

或：

```text
被砍標的
誰接棒？
```

## 標題公式

資料確認後：

```text
市場表象 + 已驗證的反直覺資金數據 + 具體標的/族群 + AI 分析鉤子
```

資料未確認前：

```text
市場表象 + 資金流向疑問 + AI 分析鉤子
```

## 2026-07-07 CTR 修正規則（生效中）

來源：近期點閱率偏低 + channel_story_log 復盤（6/24–7/2 多支【驗收】/ FIFA / JOJO 標題與封面觀看數 <30）。

### 標題

1. **禁止標題開頭使用【驗收】**，也禁止 `驗收上集點名：` 當第一個鉤子。
2. **標題前 20 字內必須有一個 structured_data 已驗證大數字**（金額、點位、成交量異常擇一）。
3. 大數字優先順序：**今日最大矛盾數字 > 外資買超第一 > 外資賣超第一 > 成交量異常**（不限定只能寫買超第一）。
4. 驗收內容可保留，但只能放**中後段**，且必須接上今日資金矛盾，不可只寫命中/失準。

範例：

```text
✅ 外資狂砸60.2億買聯電，成交量卻沒進榜？｜AI帶你看股市
✅ 台積電遭提款306億！外資卻反手60億掃聯電？｜AI帶你看股市
✅ 群創30萬張成交王卻跌！外資賣38億誰在跑？｜AI帶你看股市
❌ 【驗收】友達噴6.8%命中！外資砍45億…
❌ 7/2 驗收上集點名：2303 聯電真的動了？
```

### 封面視覺

1. **預設風格改為「財經戰情室」**：透明數據牆、法人買賣超光束、K 線與資金箭頭、博士 + 韭菜、兩行大字數據對比。
2. **暫停體育賽事 / 動漫 IP 靈感風格**（FIFA、JOJO、忍者龜、甄嬛、漫威等）作為預設或 A 組；至少連續 2–4 週以戰情室為主，待 CTR/views 回升後再拿一組做 B 測。
3. 使用者若只輸入 `/2` 不帶主題 → 自動用戰情室；若指定體育/動漫主題 → 先提醒本規則，除非使用者堅持。

戰情室必備元素：

- 左上小日期：`M/D 台股盤後`
- 縮圖兩行大字：核心股名 + 大數字/反差
- 畫面有資金流向、買賣超對比、量價矛盾，不是裝飾性 IP 場景

## 禁止事項

- 不捏造市場數字。
- 不用【驗收】或「驗收上集點名」開頭標題（2026-07-07 起）。
- 不用體育/動漫風格當 `/2` 預設封面（2026-07-07 起，實驗暫停）。
- 不發布佔位括號。
- 不用美股紅跌綠漲的配色邏輯。
- 不把完整標題塞進縮圖。
- 不用 generic Wall Street 圖像取代台股情境。
- 不使用未授權 IP 角色或過度相似角色。
- 不把「暗流」當成每日預設詞；它和「資金輪動」一樣，用多了會變空泛套話。

## 台股配色規則（強制，2026-07-28 再強調）

來源：台股／亞股慣例；與美股相反。Agent 寫封面 prompt、視覺主題、生圖說明時必須遵守。

| 方向 | 顏色 | 英文寫法 |
|------|------|----------|
| 漲 / 多方 / 買超 / bullish / rally | **紅** | RED |
| 跌 / 空方 / 賣超 / bearish / **崩盤** | **綠** | GREEN |

具體禁令：

- **禁止**把崩盤畫成「紅雨／紅色風暴／紅色警報板當跌勢主色」。
- **禁止**把上漲／避風港強勢畫成「美股式綠箭當漲」。
- 避風港「收紅」＝紅色 K／紅燈；大盤崩跌＝綠色 K／綠雨／綠壓。
- 驗收「失準」可用紅叉當錯誤標記（語意是錯，不是漲），但跌勢 K 線仍須是綠。
- 英文 prompt 必須寫明：`Taiwan colors: red=up, green=down`，並加 `Never use US green-up/red-down`。
- 警訊可用黃黑／琥珀，但不能顛倒漲跌主色。

## 縮圖規則

- 4-6 個中文字優先。
- 只打反差核心，不重複完整標題。
- 文字要能在手機上讀清楚。
- 畫面要有資金流向箭頭、主力換股、外資提款、族群轉進等視覺符號。
- 首頁流量導向影片，縮圖大字最多兩行：第一行核心股名或衝突對象，第二行大數字或反差。
- 每張縮圖需標記版型，方便 `/4` 復盤比較。

### A/B 構圖必須不同（2026-07-29 納入）

來源：人工回饋——同一天兩張封面若鏡頭／主體比例／角色大小幾乎一樣，等於偷懶，A/B 測不到構圖效果。

- **同一視覺主題可以共用世界觀**（例如都是資金流戰情圖），但 **A/B 構圖不可複製**。
- 預設強制：
  - **A＝廣角地圖**：俯視／高角，資金路徑圖佔畫面大半，角色小、角落。
  - **B＝特寫對撞**：中近景側角，雙標的大道具前景，角色中等大小，地圖僅背景虛化。
- Prompt 必須寫明 `COMPOSITION VARIANT A/B`，並互相寫「不要用對方的鏡頭」。
- 生圖後若兩張仍像同一張改字，應重產 B，不要直接上架。
- Agent 手動 polish 封面時也要保持 A/B 構圖差異，不能兩張貼同一段 scene。

## 縮圖版型分類

每次 `/2` 產出與 `/4` 復盤時，盡量標記下列其中一種：

- 大數字衝突型：例如 `外資買80.9億`。
- 驗收命中型：例如 `景碩噴漲停`。
- 資金換手型：例如 `聯電被砍 / 華通接棒？`。
- 榜外吸籌型：例如 `買超第一卻沒進榜`。
- 恐慌反轉型：例如 `大盤重挫 / 誰被買爆`。
- 能接嗎型：例如 `華邦電能接嗎？`，需搭配失效條件。

## 2026-05-15 標題假設

來源：使用者觀察 + 5/13 影片早期表現。

待驗證假設：

- 「個股名稱 + 能接嗎？」或「個股名稱 + 還能跟嗎？」可能有較好的散戶代入感。
- 這類標題的優點是直接對應觀眾心中問題：已經漲了還能不能追？跌下來是不是能接？
- 目前樣本尚未達 900 views，不可判定為勝利公式；可作為 B 組或 Shorts/社群貼文測試角度。

使用規則：

- 不能只寫 `XX 能接嗎？`，前後要補上具體數據矛盾。
- 影片內容也要配合標題承諾：凡是點名個股，該段結尾必須給「追蹤、等待突破、避開、確認」其中一種觀察建議，並補上失效條件。
- 若今日有高討論度、高成交量，或 AI 數據觀察焦點中的個股，且同時具備法人/量價矛盾，Podcast 開場可先從這檔個股切入，再回推大盤。
- 優先格式：

```text
個股名稱 + 能接嗎？ + 外資/成交量/漲跌幅的反直覺原因
個股名稱 + 還能跟嗎？ + 今天主力是否真的還在買
```

範例：

```text
2313 華通還能跟嗎？外資買超 43.9 億卻沒進成交量榜
2344 華邦電能接嗎？漲停後外資 32.2 億還在買
```

## IP/動漫封面實驗：第一眼辨識度（2026-07-31 上架後回饋）

來源：7/31 七龍珠風實驗——人工回饋「成品沒有七龍珠感覺」（已上片，作流程改進）。

根因（v1）：

- prompt 混入戰情室／全息地圖／HUD／石碑護盾 → 模型優先畫成「科幻金融特效」
- 角色太小、岩石荒原／大氣場／速度線／變身光柱不夠 → 第一眼不像 90s 少年漫
- 只寫 “Dragon Ball-like / inspired by” 不夠；必須 **正面列出必備視覺語言**，並 **明示禁止戰情室**

之後若再做七龍珠／少年漫實驗，prompt 強制：

1. **開場第一句**：`classic 1990s Japanese shonen battle anime at first glance`
2. **必備**：岩石荒原、裂地浮石、巨大金/紅/藍白氣場球或變身光柱、放射速度線、衝擊環、賽璐璐粗黑線、定格高潮
3. **禁止**：台灣衛星地圖、全息戰情室、透明 HUD、狼群雷射、電玩石碑紀念碑、暗色科幻 UI
4. **股名載體**：用「氣場球／能量柱／護盾」標股名，不要用儀表板地圖當主體
5. **生圖後自檢 3 秒**：關掉標題文字，路人能不能說「這很像七龍珠那種戰鬥漫」？不能 → 重產，不要硬上
6. **主題字串含「（實驗）」** 才放行動漫 IP 風（日常仍預設戰情室）
