# 06_YouTube_Assets

這裡是 YouTube 相關的 active 工作區，放包裝、封面 prompt、頻道敘事紀錄與測試痕跡。

## 主要用途

- 每日 /2 的上架包與封面 prompt
- 頻道敘事紀錄與觀看數回填
- YouTube 包裝規則與實驗紀錄
- 專題型 YouTube 素材的 active / archive 交界

## 目前常用檔案

- `channel_story_log.md`：頻道敘事紀錄
- `youtube_packaging_playbook.md`：長期包裝規則
- `youtube_experiment_log.md`：包裝測試結果
- `youtube_package_YYYY-MM-DD.md`：每日上架包
- `yt_thumbnail_prompt_YYYY-MM-DD_1.md` / `_2.md`：A/B 封面 prompt

## 使用原則

1. 每天的 /2 先看 `reports/CURRENT.md`。
2. 新的上架素材優先留在這裡，不要散落到根目錄。
3. 舊封面、舊包裝、舊 metadata 再依日期移到 `reports/archive/`。
