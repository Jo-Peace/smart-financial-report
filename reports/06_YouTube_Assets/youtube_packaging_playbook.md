# YouTube 包裝複利規則

這份檔案用來保存標題、縮圖與封面 prompt 的累積規則。每次測試後更新，不要只做一次性的 daily package。

## 目前有效方向

- 數據反差：盤面表象與資金數據相反。
- 具體數字：金額、檔數、點位、百分比，但只能用已驗證資料。
- 資金流向：觀眾想知道外資、主力、投信的錢去哪裡。
- AI 角色：標題要讓 AI 有「拆解、追出、找出」的功能，不只是掛名。

## 標題公式

資料確認後：

```text
市場表象 + 已驗證的反直覺資金數據 + 具體標的/族群 + AI 分析鉤子
```

資料未確認前：

```text
市場表象 + 資金流向疑問 + AI 分析鉤子
```

## 常用鉤子

- 紅盤背後有警訊？
- 創高卻賣？
- 資金轉向
- 主力換股？
- 誰在接手？
- 外資提款
- 主力偷吃貨
- 資金暗流

## 禁止事項

- 不捏造市場數字。
- 不發布佔位括號。
- 不用美股紅跌綠漲的配色邏輯。
- 不把完整標題塞進縮圖。
- 不用 generic Wall Street 圖像取代台股情境。
- 不使用未授權 IP 角色或過度相似角色。

## 台股配色規則

- 漲 / 多方 / bullish：紅色。
- 跌 / 空方 / bearish：綠色。
- 警訊可用綠色或黃黑警示，但不能讓「上漲」看起來像美股綠色。

## 縮圖規則

- 4-6 個中文字優先。
- 只打反差核心，不重複完整標題。
- 文字要能在手機上讀清楚。
- 畫面要有資金流向箭頭、主力換股、外資提款、族群轉進等視覺符號。

## 2026-05-06 新增規則

來源：YouTube 內建 AI 建議 + 人工修正。

- 可以採用「數據矛盾與反差」、「特定數字與急迫性」、「跟隨資金流向」三方向。
- 但在資料未確認前，只能用無數字版本。
- 例：`台股紅盤背後有警訊？AI 追出資金真正流向`
- 等外資買賣超、族群、檔數、點位確認後，才升級成資料版標題。
