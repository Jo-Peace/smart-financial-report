## Archive 原則

舊的每日報告、structured data、NotebookLM prompt、YouTube package 與舊縮圖，移到 `archive/` 對應分類。

不要刪舊資料；舊資料用來回看標題、封面、觀看數與預測表現，讓包裝策略和選股策略持續複利。
