# docs

專案文件入口。

## 建議閱讀順序

1. `PROJECT_MAP.md`：先看整體工作區怎麼分層
2. `architecture.md`：看程式與資料層的拆法
3. `workflows.md`：看每日盤後、週末與工具流程
4. `optimization_backlog.md`：看目前已知的優化待辦與設計決策
5. `special_topic_workflow.md`：看週末 / 專題的標準流程
6. `ROOT_ENTRYPOINTS_AND_WRAPPERS.md`：看 root 入口與相容層對照

## 文件角色

- `PROJECT_MAP.md`：工作區導覽與 source-of-truth 說明
- `architecture.md`：架構總覽
- `workflows.md`：流程說明
- `optimization_backlog.md`：優化項目與長期方向
