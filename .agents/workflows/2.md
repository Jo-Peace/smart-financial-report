## 核心原則

`/2` 是封面與 YouTube 包裝階段。它必須在 `/1` 產生 `daily_report` 與 `structured_data` 後執行。

`/1` 不再產生封面 Prompt、縮圖 Prompt 或 YouTube package；避免在資料尚未確認、視覺主題尚未決定前產出需要大量返工的封面內容。

## 2026-07-07 起生效的包裝規則（CTR 修正）

完整說明見 `reports/shared/youtube_packaging_playbook.md` 的「2026-07-07 CTR 修正規則」。

執行 `/2` 時必須遵守：

1. **標題禁止開頭【驗收】**，也禁止 `驗收上集點名：` 當第一個鉤子。
2. **標題前 20 字內必須有 structured_data 已驗證大數字**（矛盾數字 > 外資買超第一 > 外資賣超第一 > 成交量異常）。
3. **使用者只輸入 `/2` 時不帶視覺主題**：腳本用本機場景庫自動選今日場景（見下方「每日自動場景」），「財經戰情室」只作備援；暫停體育/動漫 IP 靈感作為預設。

## 使用方式

- `/2` → 每日自動場景（本機、決定性，同日同主題；推薦）；產不出來時才用「財經戰情室」
- `/2 財經戰情室` → 明確指定戰情室
- `/2 貨櫃碼頭／吊臂換櫃漫畫（漲紅跌綠）：…` → 自己指定今日場景（照舊）
- `/2 黑客帝國` → 可執行，但若屬體育/動漫類主題，先提醒 2026-07-07 規則並建議改戰情室

若使用者指定體育賽事或動漫風格，先說明近期 CTR 偏低、規則建議暫停；若使用者仍堅持，才帶 `--visual-theme` 執行。

## 每日自動場景（`/2` 空白時）

- 場景庫：`data/visual_scene_library.json`（日常、非 IP、非體育賽事的工廠／公用設施／交通／零售／實驗室／氣象…場景，每個場景有 archetype 與買超／賣超／背離比喻模板）。
- archetype 只看本機事實（structured_data 的 local_market_facts、法人榜、大盤漲跌、漲停、土洋對作、封面主角）：換手、權值提款、單股暴衝、量價背離、漲停鎖量、大盤強彈、大跌守線、土洋對作、盤整觀望。
- 排除近 5 個交易日 channel log 用過的場景（看「：」前的場景名）、`data/packaging_bans.json` 有效的場景禁用，以及近 5 個交易日 channel log 主題裡「禁止A／B／C…」清單點名的場景（每天重貼就持續有效，停貼 5 個交易日後失效）；近 20 個交易日沒用過的優先；以日期為種子挑選，同日同資料一定同主題。
- 主題格式：「<場景>漫畫（漲紅跌綠）：<比喻>；<博士／韭菜動作>」，≤150 字；不再寫「A兩行…，B短句大字」這類 A/B 封面字指示（封面字由本週 A/B 假設決定）。比喻裡的主角、金額、漲跌就是封面事實對帳用的同一組；對照股優先用標題 A 點名的反方向個股。顏色標的是外資買賣方向（買超紅色、賣超綠色）；股價漲跌用文字寫（噴／跌／守平盤），所以「買超卻下跌」會是紅色物件配「卻跌3.1%」。
- 不呼叫 Gemini；Gemini 不決定場景。
- 使用者若指定體育賽事或動漫風格，仍先提醒 2026-07-07 規則（見上方）。

## 封面 A/B 測試（單一變數）

- 每週一個假設（`data/ab_test_plan.json`，依 ISO 週輪替；`AB_HYPOTHESIS=H2` 可覆寫）：H1 畫風（漫畫場景 vs 戰情室數據大字牌）、H2 封面字（陳述句 vs 問句）、H3 角色（有雙角色 vs 無角色純數據）、H4 數字大小／位置。
- 封面 A/B 同主角、同一個已驗證數字、同配標題 A、同場景與構圖，只差本週變數（H1 測畫風時場景本身就是變數，只保留同構圖；B 的數據大字牌不畫比喻場景）；兩份 Prompt 都有 `- A/B variable: …`。當日主題就是「財經戰情室」時，H1 兩組會幾乎一樣，當天自動改測下一個假設（Prompt 會宣告實際測的假設）。
- 上架：用標題 A；在 YouTube Studio「測試與比較」同時上傳封面 A/B。標題 B 留給之後單獨的標題測試，不同時進行。
- YouTube 回報勝出後記錄：`python3 cli.py youtube record-ab-result --date YYYY-MM-DD --winner a|b|none --value-a X --value-b Y`。封面 Prompt 沒有 `- A/B variable:`（單一變數之前的舊封面）時指令會拒絕記錄；確定是某假設的單一變數測試才加 `--hypothesis H1`。
- 同一假設 ≥3 次有勝負且過半才建議升級預設（要手動改 `modules/cover_ab_test.py` 的 `LEVER_DEFAULTS`，不會自動套用）；A/B 結果不產生禁令。

## 固定角色設計規範

每次產出視覺 Prompt 時，必須帶入以下兩個角色作為封面主角。戲服與背景依本次視覺主題調整，但角色外觀特徵不得改變。

### 角色 A：數據張博士

- 台灣男性，40 歲左右，知性氣質
- 固定外觀：深色西裝或當日主題戲服、黑框圓眼鏡、手持平板或數據螢幕、神情冷靜自信、偵探姿態
- 當日可調整：戲服換成本次主題，手指向當日核心個股或關鍵數字

### 角色 B：熱血阿明（韭菜散戶）

- 台灣男性，30 歲左右，親切感
- 固定外觀：寬鬆 T 恤或當日主題服裝，顏色帶韭菜綠元素，誇張表情，手持看盤手機
- 必須保留韭菜辨識度：頭上有小韭菜葉造型髮束或韭菜綠頭飾，服裝至少一處有明顯韭菜綠
- 當日可調整：服裝材質、配件與背景跟博士同步，但不可失去韭菜綠與韭菜葉輪廓

## 執行步驟

1. 解析 `/2` 後方文字為 `VISUAL_THEME`；有文字就帶 `--visual-theme`（一律優先）。空白時不帶參數，由腳本決定並印出來源：
   - `logged`：今天 channel log 已有操作者稍早設定的主題 → 同日重跑沿用；
   - `auto`：否則用本機場景庫自動選今日場景（見下方「每日自動場景」）；
   - `fallback`：產不出自動場景時才用「財經戰情室」。
   前一天的視覺主題永遠不沿用。

2. 確認今日 `/1` 產物存在：
   - `reports/daily/YYYY-MM-DD/daily_report.md`
   - `reports/daily/YYYY-MM-DD/structured_data.json`

3. 執行素材生成腳本：

   ```bash
   python3 cli.py youtube regen-assets --date YYYY-MM-DD --skip-podcast --skip-wiki
   ```

   若要指定視覺主題：

   ```bash
   python3 cli.py youtube regen-assets --date YYYY-MM-DD --skip-podcast --skip-wiki --visual-theme "財經戰情室"
   ```

   若同一天已有 package 但要重產，加 `--force-youtube`。

   `--visual-theme` 只寫正向視覺場景（場景＋比喻＋角色動作，合計 ≤150 字）；不要再寫「A兩行股名+金額，B短句大字」這類封面字版型——封面字由本週 A/B 假設決定，腳本會把這類舊指示從主題移除。
   腳本逐句拆解：「禁止／不要／不得／勿用…」子句與禁用股名／場景存進 `data/packaging_bans.json`
   （5 個交易日到期、重貼不延長、每類有上限、前四分位結構自動豁免），標題類禁令只注入標題 prompt 一次；
   畫面類禁令（Logo、IP 角色、配色）與已用場景只列在 preflight 供人工參考，不進任何生圖 prompt。
   標題／口播指示（例如「上一交易日說上週四」「今天週二，明天開盤可以說」）視為「今日操作者指示」，
   只在貼上的那個交易日注入標題 prompt；每天要用就每天貼。
   正向場景會進封面 Prompt、NotebookLM 封面指令與 channel log 視覺欄。

   標題定案後腳本預設會依標題 A/B 重產 NotebookLM 導演卡（即使帶 `--skip-podcast`），
   讓前 30 秒兌現標題；若已上傳舊卡請刪除後重傳。不想重產時加 `--skip-director-align`。

4. 腳本會讀取 `/1` 的資料並產出：
   - `reports/youtube/YYYY-MM-DD/youtube_package.md`
   - `reports/youtube/YYYY-MM-DD/yt_thumbnail_prompt_1.md`
   - `reports/youtube/YYYY-MM-DD/yt_thumbnail_prompt_2.md`
   - 更新 `reports/shared/channel_story_log.md` 的視覺風格欄位

5. 執行 `/2` 後檢查：

   ```bash
   python3 cli.py youtube check-youtube-package --date YYYY-MM-DD
   ```

   若檢查失敗，先修正缺漏再回覆使用者。特別注意：

   - 兩份縮圖 Prompt 都必須包含左上小日期，例如 `7/7 台股盤後`
   - 封面 A/B 主角或數字不同會 FAIL；沒宣告 `- A/B variable:` 會 WARN
   - 標題 A 開頭不可是【驗收】或「驗收上集點名」
   - 標題前半段要有已驗證大數字

6. 回覆使用者時列出：
   - 今日使用的視覺主題與來源（explicit / logged / auto / fallback）
   - YouTube package 路徑
   - 兩個縮圖 Prompt 路徑
   - 標題 A/B 摘要
   - 本週封面 A/B 變數（與上架用 Studio「測試與比較」的提醒）

## 包裝邏輯要求

`/2` 必須讀取 `/1` 已產出的 structured data，不得重新猜今日主題。

標題與封面必須優先使用：

- 今日最強異常（量價矛盾、榜外吸籌、天量派發）
- 外資/投信/法人具體買賣超金額
- 昨日預測驗收（僅作中後段延續，不作開場）
- 最近頻道觀看數與標題學習

封面 Prompt 必須服務標題，不可只套主題皮膚。視覺主題是表現方式，台股數據矛盾才是內容主體。

## 禁止事項

- 不在 `/1` 指定封面視覺風格。
- 不在 `/1` 產 YouTube package 或縮圖 Prompt。
- 不保留前一天視覺主題。
- 不讓 Gemini 決定每日視覺場景（空白時只用本機場景庫）。
- 不用【驗收】或「驗收上集點名」開頭標題。
- 不用體育/動漫風格當 `/2` 預設封面（2026-07-07 起暫停實驗）。
- 不使用未授權 IP 角色或過度相似角色。
- 不把完整影片標題塞進縮圖。
- 不產生沒有具體個股、金額或數據矛盾的泛用封面。
