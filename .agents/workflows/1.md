1. 檢查使用者是否有附帶參數。
   - 如果是裸字串，例如 `/1 忍者龜`、`/1 黑客帝國`、`/1 灌籃高手`，請把它視為「每日視覺設定」，設定：
     `export DAILY_VISUAL_THEME="使用者提供的視覺設定"`
     `export THUMBNAIL_STYLE="使用者提供的視覺設定"`
   - 如果使用者明確寫 `主題是...` 或 `專案狀態：...`，才設定：
     `export PROJECT_THEME="使用者提供的市場/專案主題"`
   - 如果兩者都有，例如 `/1 主題是GTC展 視覺設定忍者龜`，請同時設定 `PROJECT_THEME` 與 `DAILY_VISUAL_THEME`。
   - 如果使用者只輸入 `/1`，則不設定主題，使用日常盤勢預設風格。
2. 使用 `run_command` 工具，在 `/Users/shenghanchou/Desktop/AntiGravity專案/stock-youtube/smart_financial_report` 目錄下執行 `python3 main.py`（若有主題請加上環境變數前綴）。
// turbo-all
2. 持續使用 `command_status` 監聽腳本直到完全執行完畢。
3. 腳本成功結束後，主動去找 `reports/` 底下今天最新生成的 `daily_report` 與 `notebooklm_prompt` 檔案，簡單總結一下重點標題。
4. 詢問使用者是否需要直接輸入 `/2` 來繼續產生對應的 YouTube 視覺與文案。
