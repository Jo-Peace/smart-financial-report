## 目的

`/5` 是每月實驗快捷。它不是日常復盤，而是用來回答較大的系統問題，例如：

- IP 靈感封面是否比純金融懸疑封面有效？
- 長標題數據型是否比短標題疑問型有效？
- `/2` 產出的 A/B 是否真的被上架使用？
- YouTube API 自動回填是否足夠，還需要截圖補哪些後台數據？

## 執行步驟

1. 先跑 `/4` 的資料更新與復盤流程。

2. 選一個明確實驗問題，不要一次測太多：

   ```text
   本月實驗問題：
   A 是否比 B 更值得保留？
   ```

3. 收集樣本：
   - `channel_story_log.md`
   - `youtube_packaging_playbook.md`
   - `youtube_experiment_log.md`
   - `content_review_*.md`
   - `youtube_package_*.md`

4. 樣本分級：
   - `>= 900 views` 才可作為主要判斷。
   - `300-899 views` 只能當輔助觀察。
   - `< 300 views` 不作為勝負依據。

5. 產出月度實驗檔：

   ```text
   reports/06_YouTube_Assets/monthly_experiment_YYYY-MM.md
   ```

6. 若實驗結論穩定，寫回：
   - `youtube_packaging_playbook.md`
   - 必要時更新 `.agents/workflows/2.md`

## 禁止事項

- 不用低樣本硬判勝負。
- 不同時比較太多變因。
- 不把「主題剛好熱門」誤判成「封面風格有效」。
- 不把實際上架後手動改過的標題當成原始 A/B 勝負。
